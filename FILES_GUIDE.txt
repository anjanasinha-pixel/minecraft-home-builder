📁 JAVASCRIPT GAME ENGINE (js/ folder)
──────────────────────────────────────────────────────────────────────────

These files contain the game logic. In order of importance:

1. ⚙️ game.js
   - The main game loop that keeps everything running
   - Handles menus, pause, resume
   - Manages all game systems
   - MOST IMPORTANT FILE

2. 🌍 world.js
   - Creates and manages the game world
   - Generates terrain
   - Handles block rendering
   - Creates lighting and sky

3. 🧱 block.js
   - Defines what blocks are
   - Creates block 3D models
   - Manages block storage

4. 👤 player.js
   - Creates player characters (Reyansh & Anjana)
   - Handles player movement
   - Creates animated avatars
   - Manages player physics

5. 📷 camera.js
   - Controls the first-person camera
   - Handles mouse look (pointer lock)
   - Moves camera with player

6. ⌨️ input.js
   - Reads keyboard and mouse input
   - Handles key presses
   - Manages block placement/removal clicks

7. 🖼️ ui.js
   - Manages all menus and UI
   - Shows notifications
   - Handles button clicks
   - Updates player information

8. ⚙️ constants.js
   - All game settings in one place
   - Block types, colors, sizes
   - Player properties
   - Control speeds and physics

==============================================================================
                         HOW TO USE THE GAME
==============================================================================

STEP 1: Open launcher.html
- Double-click launcher.html
- Or drag it into a web browser
- A beautiful welcome screen appears

STEP 2: Click "Start Game Now!"
- The game will load (1-2 seconds)
- Click in the game area to lock your mouse
- You're ready to play!

STEP 3: Start Building!
- Use WASD to move
- Click to place blocks
- Right-click to remove blocks
- Have fun!


==============================================================================
                         CUSTOMIZATION GUIDE
==============================================================================

Want to customize the game? Here's what you can change:

EASY CUSTOMIZATION (Edit these files directly):

1. In styles.css:
   - Change colors (search for hex codes like #87CEEB)
   - Modify font sizes
   - Adjust button styles

- js/game.js: Change game mechanics


==============================================================================
                      TROUBLESHOOTING CHECKLIST
==============================================================================

Game won't load?
✓ Make sure launcher.html or index.html exists
✓ Try opening in Chrome, Firefox, or Edge
✓ Check that JavaScript is enabled
✓ Clear browser cache (Ctrl+Shift+Delete)

Can't move?
✓ Click in the game area first (focus it)
✓ Press W to move forward
✓ Check caps lock isn't on

Can't place blocks?
✓ Look directly at an existing block
✓ Make sure you're close enough (within ~10 units)
✓ Try left-clicking

Game is slow/laggy?
✓ Close other browser tabs
✓ Close other programs
✓ Try reducing window size
✓ Use a different computer

Saved world disappeared?
✓ Check if browser cleared cache
✓ Try opening the game again
✓ World data is stored in browser's local storage

Commands not working?
✓ Check if game is paused (press ESC)
✓ Click in game area to focus it
✓ Try different keyboard layout
